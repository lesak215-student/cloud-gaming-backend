## Описание

Сервис для управления платформой облачного гейминга: пользователи, каталог игр и игровые сессии.

### Ресурсы

1. **Пользователи (`/users`)**:
   - `StandardUser`: 1 активная сессия, разрешение стрима до 1080p, доступ только к базовым играм (`BASIC`).
   - `PremiumUser`: до 3 активных сессий, разрешение до 4K (2160p), доступны все игры (`BASIC` и `PREMIUM`).

2. **Игры (`/games`)**:
   - Название, жанр, требуемый уровень подписки (`BASIC` или `PREMIUM`) и количество слотов на сервере.

3. **Сессии (`/sessions`)**:
   - Связывает пользователя и игру. Хранит статус (`ACTIVE`, `PAUSED`, `COMPLETED`), разрешение и время игры.

### Операции по правилам предметной области

- **Запуск сессии (`POST /sessions`)**: проверяет тариф пользователя, лимит одновременных сессий и свободные места на сервере игры.
- **Пауза (`POST /sessions/{id}/pause`)**: ставит активную сессию на паузу.
- **Возобновление (`POST /sessions/{id}/resume`)**: снимает сессию с паузы.
- **Завершение (`POST /sessions/{id}/terminate`)**: завершает сессию и освобождает слот игры.

### Фильтрация

- Пользователи: по тарифу (`tier=BASIC|PREMIUM`).
- Игры: по жанру (`genre`), тарифу (`tier`) и свободным слотам (`hasSlots=true|false`).
- Сессии: по пользователю (`userId`), игре (`gameId`) и статусу (`status=ACTIVE|PAUSED|COMPLETED`).

### Запуск и проверка

Запуск сервера:
```bash
mvn exec:java
```

Запуск проверки curl-запросами:
```bash
bash requests.sh
```
